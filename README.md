# Overview

Welcome to the repository! This project contains several folders, each housing Docker Compose files necessary for hosting various services or components as indicated by the folder names. This work is a product of my studies at Ynov Toulouse Campus.

# Folder Structure

The repository is organized as follows:

    gitlab/
        docker-compose.yml
        [Other related files]

    mattermost/
        docker-compose.yml
        [Other related files]

    ...

Each folder contains a docker-compose.yml file that defines the configuration needed to deploy the respective service(s). 
You can find all the necessary details about each service in the individual folders.

# Getting Started

To get started with any of the services :

- Clone the repository to your local machine:

    `git clone https://github.com/jaslieb/docker-ynov.git`

- Navigate to the desired service folder:
     
    `cd folder_name`

- Start the service using Docker Compose:
     
    `docker-compose up`

Make sure you have Docker and Docker Compose installed on your machine.
